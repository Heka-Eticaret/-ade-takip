# Palette's Journal

## 2025-05-18 - Segmented Toggle Buttons & Disabled Actions
**Learning:** Segmented control buttons and state action buttons benefit greatly from explicit `aria-pressed` states and descriptive hover tooltips (`title`) when disabled, giving keyboard and screen-reader users clarity on current selection and reasons for disabled states.
**Action:** Always include `aria-pressed` on toggle-like action buttons and `title`/aria descriptions on disabled controls.
