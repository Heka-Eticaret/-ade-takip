# Palette's Journal

## 2025-05-18 - Actionable Empty States in Filtered Dashboards
**Learning:** In dashboards with persistent default filters (e.g., initial filter set to "Kontrol bekleyenler" rather than "Tümü"), a generic empty state causes confusion about whether records are missing or filtered out. Providing direct contextual CTA buttons (clearing filters vs opening creation modal) eliminates dead ends for warehouse operators.
**Action:** When designing empty states for filtered data tables or lists, always differentiate between zero total items and zero filter matches, pairing each with an instant corrective action.
